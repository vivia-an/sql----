# 天府医院LIS数据添加说明

## 概述
在原有`运管科lis报表整体 同比环1.sql`基础上，添加天府医院独立统计行，天府医院数据来源于单独的数据库（hid0117）。

## 数据血缘分析

### 原有数据（hid0101）
```
数据源: hid0101_orcl_lis_dbo
包含表:
  - lis_inspection_sample (检验样本表)
  - lis_inspection_sample_charge (样本收费表)
  
统计维度:
  - 按亚专业组代码(GROUP_ID)分类
  - 包含多个院区：主院区、温江院区、天府院区、锦江院区
```

### 天府医院独立数据（hid0117）
```
数据源: hid0117_orcl_lis_dbo
包含表:
  - lis_inspection_sample (检验样本表)
  - lis_inspection_sample_charge (样本收费表)
  - lis_requisition_item (医嘱项目表) - 用于排除特定项目
  
数据特点:
  - 排除 GROUP_ID = 'G050' 的数据
  - 排除特定收费项目: 'LIS0301', 'LIS027534', 'LIS024805', 'LIS01566', 'LIS01414', 'LIS027420'
```

## SQL修改说明

### 1. 新增CTE（公共表表达式）

#### tianfu_data - 天府医院当月数据
```sql
统计字段:
  - 标本数: COUNT(DISTINCT inspection_id)
  - 工作量: SUM(workload)
  - 收费金额: SUM(charge)
  
筛选条件:
  - inspection_date: 当月日期范围 (上个月)
  - GROUP_ID <> 'G050'
  - 逻辑删除: isdeleted = '0'
  - NOT EXISTS: 排除特定收费项目
```

#### tianfu_data_last_month - 天府医院上月数据
```sql
统计字段: 与当月相同，字段名加"上月"前缀
筛选条件:
  - inspection_date: 上上个月日期范围
  - 其他条件与当月相同
```

#### tianfu_data_last_year - 天府医院去年同期数据
```sql
统计字段: 与当月相同，字段名加"去年同期"前缀
筛选条件:
  - inspection_date: 去年同期日期范围
  - 其他条件与当月相同
```

### 2. 修改summary_with_totals

在原有的三个UNION ALL分支后，添加第四个分支：

```sql
UNION ALL

-- 天府医院独立统计行
SELECT 
    统计月,
    '实验医学科(检验科)' as 运管科室,
    '天府医院' as 运管院区,
    '天府医院' as 亚专业组,
    
    -- 三个周期的数据
    当月标本数、当月项目数、当月总收入,
    上月标本数、上月项目数、上月总收入,
    去年同期标本数、去年同期项目数、去年同期总收入,
    
    -- 环比增长率
    标本数环比增长率%, 项目数环比增长率%, 收入环比增长率%,
    
    -- 同比增长率
    标本数同比增长率%, 项目数同比增长率%, 收入同比增长率%,
    
    -- 收入占比 (暂时为0，因数据源不同)
    0.00 as 总收入占比%, 0.00 as 上月总收入占比%, 0.00 as 去年同期总收入占比%
    
FROM tianfu_data, tianfu_data_last_month, tianfu_data_last_year
```

### 3. 修改最终排序

```sql
ORDER BY 
    CASE 
        WHEN "亚专业组" = '合计' THEN 1
        WHEN "亚专业组" = '本部实际量' THEN 2
        WHEN "亚专业组" = '天府医院' THEN 3  -- 新增
        ELSE 4
    END,
    "标本数" DESC;
```

## 特殊处理说明

### 1. 排除的收费项目
```
'LIS0301'    - 具体项目名称需确认
'LIS027534'  - 具体项目名称需确认
'LIS024805'  - 具体项目名称需确认
'LIS01566'   - 具体项目名称需确认
'LIS01414'   - 具体项目名称需确认
'LIS027420'  - 具体项目名称需确认
```

### 2. 排除的专业组
```
'G050' - 温江院区某专业组，天府医院统计时需排除
```

### 3. 收入占比处理
由于天府医院数据来源于不同数据库（hid0117），无法与主数据库（hid0101）的总收入进行占比计算，因此：
- 总收入占比% = 0.00
- 上月总收入占比% = 0.00
- 去年同期总收入占比% = 0.00

如需计算准确占比，需要将两个数据源的总收入合并计算。

## 数据质量检查建议

1. **时间范围一致性检查**：确认天府医院三个周期的数据时间范围与主数据一致
2. **逻辑删除筛选**：确认所有表都添加了 isdeleted = '0' 条件
3. **NOT EXISTS性能**：如数据量大，考虑优化为LEFT JOIN方式
4. **NULL值处理**：所有数值使用COALESCE处理，避免NULL导致计算错误
