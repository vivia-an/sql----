# 天府医院数据字段血缘说明

## 核心SQL逻辑

### 数据来源
```
天府医院数据源：hid0117_orcl_lis_dbo
主院区数据源：hid0101_orcl_lis_dbo
```

### 字段血缘关系

#### 标本数
```
字段来源：COUNT(DISTINCT T.inspection_id)
表血缘：hid0117_orcl_lis_dbo.lis_inspection_sample
筛选条件：
  ✓ isdeleted = '0'
  ✓ GROUP_ID <> 'G050'
  ✓ inspection_date 在对应周期范围内
  ✓ 排除特定收费项目
```

#### 项目数（工作量）
```
字段来源：SUM(COALESCE(CAST(B.workload AS DOUBLE), 0))
表血缘：
  - hid0117_orcl_lis_dbo.lis_inspection_sample_charge.workload
关联条件：
  - T.inspection_id = B.inspection_id
  - B.isdeleted = '0'
```

#### 总收入（收费金额）
```
字段来源：SUM(COALESCE(CAST(B.charge AS DOUBLE), 0))
表血缘：
  - hid0117_orcl_lis_dbo.lis_inspection_sample_charge.charge
关联条件：
  - T.inspection_id = B.inspection_id
  - B.isdeleted = '0'
```

### 排除逻辑血缘

#### NOT EXISTS子查询
```sql
NOT EXISTS (
    SELECT 1
    FROM hid0117_orcl_lis_dbo.lis_requisition_item Q
    WHERE Q.requisition_id = T.requisition_id
        AND Q.charge_item_id IN (
            'LIS0301', 'LIS027534', 'LIS024805',
            'LIS01566', 'LIS01414', 'LIS027420'
        )
        AND Q.isdeleted = '0'
)

说明：
- 通过医嘱项目表(lis_requisition_item)排除特定收费项目
- 关联键：requisition_id
- 排除的是包含指定收费项目的整个检验样本
```

## 计算字段血缘

### 环比增长率
```
标本数环比增长率% = (当月标本数 - 上月标本数) / 上月标本数 * 100
项目数环比增长率% = (当月项目数 - 上月项目数) / 上月项目数 * 100
收入环比增长率%   = (当月总收入 - 上月总收入) / 上月总收入 * 100

使用函数：NULLIF(分母, 0) 避免除零错误
使用函数：ROUND(结果, 2) 保留两位小数
```

### 同比增长率
```
标本数同比增长率% = (当月标本数 - 去年同期标本数) / 去年同期标本数 * 100
项目数同比增长率% = (当月项目数 - 去年同期项目数) / 去年同期项目数 * 100
收入同比增长率%   = (当月总收入 - 去年同期总收入) / 去年同期总收入 * 100

使用函数：NULLIF(分母, 0) 避免除零错误
使用函数：ROUND(结果, 2) 保留两位小数
```

## 数据源表结构依赖

### lis_inspection_sample (检验样本表)
```
使用字段：
  ✓ inspection_id     - 样本ID (主键，关联键)
  ✓ requisition_id    - 医嘱ID (关联医嘱项目表)
  ✓ GROUP_ID          - 亚专业组代码 (筛选条件)
  ✓ inspection_date   - 检验日期 (时间范围筛选)
  ✓ isdeleted         - 逻辑删除标识
```

### lis_inspection_sample_charge (样本收费表)
```
使用字段：
  ✓ inspection_id     - 样本ID (关联键)
  ✓ workload          - 工作量 (统计字段)
  ✓ charge            - 收费金额 (统计字段)
  ✓ isdeleted         - 逻辑删除标识
```

### lis_requisition_item (医嘱项目表)
```
使用字段：
  ✓ requisition_id    - 医嘱ID (关联键)
  ✓ charge_item_id    - 收费项目ID (排除条件)
  ✓ isdeleted         - 逻辑删除标识

用途：NOT EXISTS排除特定收费项目
```

## 关键注意事项

1. **字段类型转换**：所有数值字段需 CAST AS DOUBLE，因为大数据平台统一为VARCHAR
2. **逻辑删除**：所有表都要加 isdeleted = '0' 筛选
3. **中文字段名**：Presto要求用双引号包围
4. **日期格式**：inspection_date 为VARCHAR类型，格式为'YYYYMMDD'
5. **NULL处理**：使用COALESCE避免NULL影响计算
6. **除零保护**：使用NULLIF(分母, 0)避免除零错误
