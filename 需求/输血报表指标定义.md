## 分项说明（证据链摘要）


| 指标      | 指标定义                               | 计算公式要点                                                                      | 指标来源（系统/表）                                                                                                    |
| ------- | ---------------------------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| 输血样本数   | 输血科专业组下送检样本及关联输血申请的标本规模           | LIS：`lis6_inspect_sample` 与收费明细关联，按 `group_id` 过滤；血型类可与 `bis6_req_*` 合并统计人次 | `hid0117_orcl_lis_xhdata.lis6_inspect_sample`、`lis_inspection_sample_charge`；`bis6_req_info`、`bis6_req_blood` |
| 输血检测项目数 | 纳入清单的检验项目名称种数，含效价等项目折算规则           | `COUNT(DISTINCT 项目名称)` + 效价等加项（见简化版 `project_list`）                         | 同上 `base_stats`                                                                                               |
| 输血总工作量  | 检测工作量 + 血库作业量 + 抗体筛查 + 治疗性单采 + 盘点等 | `SUM(工作量)` + 出入库袋数 + 各增量项（见简化版最终 SELECT）                                    | LIS workload；BIS 血袋、库存、抗体筛查等                                                                                  |
| 输血总收入   | 配血检 + 血费 + 输血治疗（业务确认是否含其他）         | 三类收入相加                                                                      | `LIS提示词` 3.6；DC `Fee_BillDet`                                                                                 |
| 输血总支出   | 血液成本 + 试剂等                         | 血费支出 + 试剂支出                                                                 | 血站 + 试剂库                                                                                                      |
| 配血检收入   | 检验侧标本检测收入                          | `SUM(charge)` 按检验收费项；或与总收入−血费交叉验证                                           | LIS 收费明细；提示词：当月 LIS 总收入 − 当月血费                                                                                |
| 血费收入    | 血液制品出库计费                           | 血袋与收费表关联汇总                                                                  | `BIS6_BLOODBAG_INPUT`、`bis6_charged_info`、`xinghe_charged_list` 等                                             |
| 血费支出    | 血液采购成本                             | 血站结算单据汇总                                                                    | 血站系统                                                                                                          |
| 输血试剂支出  | 输血业务试剂成本                           | 试剂订单或科室领用汇总                                                                 | 试剂库                                                                                                           |

## 需业务/财务确认项（避免口径歧义）

1. **输血总收入**是否严格等于「配血检收入 + 血费收入 + 输血治疗收入」，是否另有挂号/材料等并入总收入。
2. **样本数**用人次合计还是 `count(distinct inspection_id)`，与报表历史口径需一致。
3. **院区/主院区/天府**是否拆表，与 `运管输血报表sql-报表-lis部分天府*.sql` 分院区脚本一致。
4. **试剂支出**是否仅「输血科领用」还是含中心库分摊。
