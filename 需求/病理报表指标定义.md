## 分项说明（证据链摘要）


| 指标            | 指标定义                  | 计算公式要点                                                         | 指标来源                                 |
| ------------- | --------------------- | -------------------------------------------------------------- | ------------------------------------ |
| 病理检查治疗人次/项次   | 病理科已审核报告/标本条数         | `COUNT(1)`，`f_blk` 为报表枚举（普通外检、冰冻、细胞学、体检、各院区前缀等），`f_bgzt='已审核'` | `hid0101_mssql_bl_rep.t_jcxx`        |
| 病理检查治疗收入(元)   | 接收科室为病理科系的 HIS/收入明细金额 | `SUM(TotalFee)`，`SUBSTRING(chargedttm,1,7)=统计月`                | `m1.mdr_income`（建议与源表确认 `IsDeleted`） |
| 穿刺中心细胞病理收入（元） | 穿刺中心 + 固定医嘱名称清单       | `SUM(TotalFee)` + 接收科室 + `OrderName` 白名单                       | `m1.mdr_income`                      |
| 体检病理收入（元）     | 体检收费中病理/液基等固定项目名称     | `SUM(计算金额)`，qty 与 FactPrice 规则见 SQL                            | `m1.mdr_peisincome`                  |
| 病理其他收入（元）     | 预留项                   | **当前实现恒为 0**                                                   | 无独立来源                                |
| 病理收入合计        | 主院区三项之和               | 检查治疗 + 穿刺 + 体检（**不含**其他收入占位）                                   | 三 CTE 相加                             |
| 病理领用材料试剂费(元)  | 病理科耗材出库               | `SUM(amountmoney)`                                             | `datacenter_db.inventory_del_dets`   |
| 材料试剂费占收入比例（%） | 成本占收入                 | 材料费 ÷ 病理收入合计 × 100                                             | 上两行                                  |

## 与多院区总表关系（供扩展）

`病理运管报表汇总1.sql` 另有 **上锦收入合计**、**天府收入合计**、**总收入合计(元)**（多院区本部合计相加）。若「病理收入合计」需含上锦/天府，应以该文件「总收入合计」逻辑为准，与单列「病理科主要运行指标分析」主院区口径区分。

## 需业务/财务确认项

1. **mdr_income** 是否统一过滤 `IsDeleted='0'`（`病理收入` 片段含此条件，`病理运管报表汇总1.sql` 部分片段未写，需与视图定义核对）。
2. **病理其他收入** 是否长期为 0；若需真实值，需明确收费项范围。
3. **占收入比例** 分母是否用「病理收入合计」还是含其他院区「总收入合计」。
4. **体检病理收入** 报表展示名称为「本部温江第三方体检病理收入」与「体检病理收入」的对应关系（同一 SQL 块）。
