### 3.3 运管院区转换字段 (4个)

#### 转换参数
- **hostype**: `ward` (通过护理单元关联院区)
- **关联键**: `currentwardcode || '||' || medorgcode`
- **日期区间**: `beinhospdate` BETWEEN `hossdateward` AND `hosedateward`

| 序号 | 目标字段 | 转换逻辑 | 默认值 | 字典来源 |
|------|----------|----------|--------|----------|
| 1 | threecode | 非HID0101取hosc对应的threec，HID0101取护理单元对应的threecodeward | 'YGF9998' | dict_loc8→tbl_1308_h |
| 2 | threename | 同上逻辑取threen或threenameward | '三级院区待归' | dict_loc8→tbl_1308_h |
| 3 | omthreecode | 同上逻辑取omthreec或omthreecodeward | 'YGF9997' | mappingmember |
| 4 | omthreename | 同上逻辑取omthreen或omthreenameward | '运管三级院区待归' | mappingmember |

#### 转换逻辑伪代码
```python
if medorgcode != 'HID0101':
    threecode = hosp_dict[medorgcode].threec
else:
    threecode = ward_dict[wardrowkey].threecodeward  # 日期区间匹配
```

### 3.4 运管科室转换字段 (3个)

#### 转换参数
- **loctype**: `doc+loc` (优先医生，其次科室)
- **医生关联键**: `currentstaffgroupcode`
- **科室关联键**: `currentmedelementcode || '||' || medorgcode`
- **日期区间**: `beinhospdate` BETWEEN 开始日期 AND 结束日期

| 序号 | 目标字段 | 转换逻辑 | 默认值 | 字典来源 |
|------|----------|----------|--------|----------|
| 1 | omdeptcode | 优先医生字典→科室字典→默认值 | '997' | tbl_1307_h→tbl_1305_h / tbl_1306_h→tbl_1305_h |
| 2 | omdeptdesc | 同上 | '运管科室待归' | tbl_1305_h |
| 3 | omdeptid | 同上 | '88' | tbl_1305_h |

#### 转换逻辑伪代码
```python
if doc_dict[currentstaffgroupcode] is not None:  # 日期区间匹配
    omdeptcode = doc_dict.ygdocloccode
    omdeptdesc = doc_dict.ygdoclocname
    omdeptid = doc_dict.ygdoclocid
elif loc_dict[locrowkey] is not None:  # 日期区间匹配
    omdeptcode = loc_dict.ygloccode
    omdeptdesc = loc_dict.yglocname
    omdeptid = loc_dict.yglocid
elif currentmedelementcode is None:
    omdeptcode = '998'
    omdeptdesc = '七级科室空值'
    omdeptid = '87'
elif currentstaffgroupcode is None:
    omdeptcode = '996'
    omdeptdesc = '医疗组长空值'
    omdeptid = '89'
else:
    omdeptcode = '997'
    omdeptdesc = '运管科室待归'
    omdeptid = '88'
```

## 五、特殊逻辑说明

### 5.1 字典版本控制
所有字典表都使用以下逻辑获取最新版本：
```sql
WHERE __dictionary_id = (SELECT MAX(__dictionary_id) FROM 表名)
  AND __changeindex = (SELECT MAX(__changeindex) FROM 表名 WHERE code = 外层表.code)
```

### 5.2 日期区间匹配
关联字典时需要满足日期在有效期内：
- 开始日期为NULL时，默认为 `'1900-01-01 00:00:00'`
- 结束日期为NULL时，默认为 `'2099-12-31 00:00:00'`
- 匹配条件: `业务日期 >= 开始日期 AND 业务日期 <= 结束日期`

### 5.3 医疗机构特殊处理
- **HID0101**: 主院区，通过护理单元/科室关联字典获取院区信息
- **非HID0101**: 分院区，直接从医院字典(tbl_1308_h)获取院区信息

### 5.4 运管科室优先级
1. 优先通过医生工号(`currentstaffgroupcode`)关联 `tbl_1307_h` 获取
2. 其次通过科室编码(`currentmedelementcode`)关联 `tbl_1306_h` 获取
3. 最后使用默认值

### 5.5 默认值编码说明
| 编码 | 名称 | ID | 含义 |
|------|------|-----|------|
| 997 | 运管科室待归 | 88 | 无法匹配到运管科室 |
| 998 | 七级科室空值 | 87 | 源数据科室编码为空 |
| 996 | 医疗组长空值 | 89 | 源数据医生编码为空 |
| YGF9998 | 三级院区待归 | - | 无法匹配到三级院区 |
| YGF9997 | 运管三级院区待归 | - | 无法匹配到运管院区 |

## 七、性能优化建议

1. **字典表广播**: 原PySpark使用 `F.broadcast()` 对字典表进行广播，SQL实现时建议将字典表做成临时表或物化视图
2. **分区写入**: 目标表按 `repdate, rephour` 分区，建议使用 `INSERT OVERWRITE PARTITION` 方式写入
3. **日期索引**: 字典表的日期字段建议添加索引，提升区间查询效率
4. **字典缓存**: 频繁使用的字典可以考虑缓存或预计算
