**D3（中文版）** — 两轨各出 `main_cn.tex`，`xelatex` 编译，图不翻译（图内文字保持英文，
图题翻译）。中文版是**给中文读者/院内评审看的对照稿**，不是投稿件，因此：
不套 MDPI/JMIR 版面家具，用干净的单栏中文学术版式。

> **D3 更正（轮 44）** —— 原文写"数值宏与英文版共用同一数据文件，保证两版数字不会漂移"，
> **这句只对 B 轨成立**。B 轨两版都 `\input{data_fk.tex}`、数值都经 `\dv{}` 取出，

### 轮 3（2026-07-30）— A 轨中文版开工，`main_cn.tex` 编译通过

**字体这一关踩了一个坑，值得记下来**

`Noto Sans CJK SC` **不能用**。它是 `.ttc` 字体集合，本机 TeX Live 2013 的
`xdvipdfmx` 无法从集合中取表：`xelatex` 报 **0 error**，日志末尾却是
`Error 256 (driver return code)`，驱动以 `sfnt: table not found` 失败并**把
PDF 删掉**。也就是说"0 error"和"有产出"在这里是两件事。逐个字体实测结果：

| 字体 | 驱动 |
|---|---|
| AR PL UMing CN / UKai CN | OK |
| WenQuanYi Zen Hei / Micro Hei / Micro Hei Mono | OK |
| **Noto Sans CJK SC（含 Bold）** | **FAIL** |

最终配置（正好符合中文惯例）：**宋体 AR PL UMing CN 作正文，黑体
WenQuanYi Zen Hei 作粗体与标题，楷体 AR PL UKai CN 作强调**，等宽用
WenQuanYi Micro Hei Mono。这条已写进 `main_cn.tex` 的注释，避免以后有人换回 Noto。

### 轮 4（2026-07-30）— B 轨补校验器（B5）与图定尺（B3）

**B5 `dataBase/verify_jmir.py`（56 项检查，0 失败）**

`main_jmir.tex` 是全仓库唯一**一条自动断言都没有**的稿子，而它偏偏是全新组装的

- JMIR 规定的前置件、Discussion 首子节、尾部件标题逐项在 PDF 里

  掉了一个浮动体，表现就是少一条题注
