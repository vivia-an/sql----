## 三、审稿人最可能提的意见（按杀伤力排序）

### 🔴 致命级（不解决必拒）

**R1. 结果数据的来源与可信性**
当前稿件的模型级结果与已发表文献 e71252 完全一致。任何一位读过该文的审稿人（该刊领域内，
概率很高）都会立刻发现。**这不是"需要修改"，是学术不端。**
→ 必须换成本院实测数据，且保留原始日志以备核查。

**R2. 单中心、口径不可迁移**
本文自己承认口径是 institution-specific——审稿人会反问：那这套方法对别的医院有什么价值？
→ 建议补：把"方法可迁移、口径不可迁移"这一层说透，并给出新院区接入所需的最小配置工作量
（几人日、需要哪几类元数据）。这条能把 R2 从"致命"降到"可接受的局限"。

### 🟠 重伤级（需实质性补充）

**R3. 幻觉检测器本身未被验证**
全文最关键的自动化判定（什么算幻觉）由一个自研检测器给出，但检测器的准确率没有报告。
→ 必须补：人工复核样本量 + 与检测器的一致率（Appendix 已留槽位 I9）。
建议样本 ≥100，一致率 ≥0.85，否则所有幻觉率数字都不可信。

**R4. "小模型反超"结论的稳健性**
单次运行 + 确定性解码 = 每个模型只有一个观测点。审稿人会问：换个随机种子/换批任务还成立吗？
→ 建议补：至少 3 次重复（或 3 折任务划分），报告有效率的均值±SD。
这是把 72 分推到 80 分性价比最高的一项。

**R5. 任务数偏小，统计效力不足**
N=24（或 19）任务做 8×5 析因，每格样本极少。
→ 要么扩任务集，要么明确改称 feasibility study 并调低结论强度。

### 🟡 中度（会要求修改但不致命）

**R6.** 结果集校验只有 4 条口径、3 个任务，样本太小，Jaccard 的置信区间没给。
**R7.** 与规则匹配器（RBFM）的对比不公平——RBFM 是院内旧系统，不是公认基线。建议补一个公开可比的基线（如 Criteria2Query 思路的复现，或 BM25-only 检索）。
**R8.** 成本分析用的是撰稿时点的 API 价格，需注明日期；本地 GPU 摊销假设需给出依据。
**R9.** 未报告 prompt 长度/token 消耗对成本的影响。
**R10.** 5 种 prompt 策略的选择依据没说明（为什么是这 5 种）。

### 🟢 轻度（编辑加工级）

**R11.** 所有 `[占位符]` 未填（作者、单位、IRB 号、仓库 URL、基金）。
**R12.** Criteria2Query 3.0 未引用（作者名单待补）。
**R13.** 参考文献 50 条，该刊同类文章多在 45–60 条，属正常，但可再补 2–3 条国内医院数据治理文献以支撑"口径 institution-specific"的论断。
**R14.** 图 3B 的本地模型摊销成本假设应移到正文而非只在图注。

## 四、达到 80+ 的最小工作量清单

| 优先级 | 事项 | 工作量 | 分数增益 |
|---|---|---|---|
| 1 | 用真实实测数据替换全部数值 | 取决于集群 | 0 → 72 |
| 2 | 幻觉检测器人工复核（≥100 样本，报一致率） | 1–2 人日 | +3 |
| 3 | 重复实验 3 次，报均值±SD | 集群时间 | +3 |
| 4 | 补一个公开可比基线（BM25-only 或 schema-only） | 1 人日 | +2 |
| 5 | 把"方法可迁移 / 口径不可迁移"论证写透 + 新院区接入成本 | 半人日 | +2 |
| 6 | 填齐所有占位符 | 半人日 | +1 |

## 五、这篇文章真正的强项（审稿人会认可的）

1. **"错误统计口径"这一错误类别**——通用 text-to-SQL 的错误分类里没有，是本文对领域的实质贡献。
   它产生"可执行但数字错"的失败，恰恰是医院场景最危险的一类。
2. **失败案例分析**——非计划再次手术那条（选了结构合法但全库未填充的标志位，Jaccard=0），
   语法和 schema 校验都抓不到。这类诚实的负面结果在应用类论文里很少见，是加分项。
3. **隐私约束与精度最优点重合**——本地小模型既是合规要求又恰好最准，这个收口比原文的
   "小模型反超大模型"更有故事性。
4. **可审计的数值骨架**——附录整数基数表让审稿人能自己复算每一个百分比。该刊少见，会被点赞。

## 六、结论

**版式、结构、方法学描述、参考文献、补充材料这些"形"的部分已经到位**（这也是前 7 轮做的事），
按目标刊体例几乎逐项对齐。

**卡住的只有一件事：结果部分需要真实数据。**
拿到真实数据后，这篇的水平在该刊属于中上，Major revision 后接收是合理预期。
若再补上"检测器验证 + 重复实验"两项，进入 Minor revision 区间是有把握的。
