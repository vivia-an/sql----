# 周报 / 下周计划示例

> **交付形态**：对用户输出时，整段周报必须包在 ` ```text ` 围栏内；大项 `一、` 与细则 `1、2、3…` 各占一行，大项之间空一行。勿输出成单行段落。

## 输入（零散要点）

```
在院主题峨眉东部核查；医嘱执行0123拆分；病理6月无数据已恢复；kylin告警；云原生对象存储；手麻申请单；AI内网测试；专利合同；会议学习
```

## 输出：本周工作

```text
一、在院主题峨眉/东部新区数据核查（HID0123·HID0124）
1、按在院校验、空值校验及静态检测口径，对峨眉、东部新区新进在院主题数据开展核查；
2、院区拆分规则对齐实时指标：同库 hid0123，当前科室 ct_loc.ctloc_hospital_dr 为 2→HID0123、12→HID0124，且仅在 medorgcode='HID0123' 时改写，不影响其他院区；
3、已同步调整在院主题 ETL（mdr_beinhosp / DataX starrocks-be-inhospital），改写点置于运管字典关联前，保障院区键与后续映射一致；
4、继续跟进 0123/0124 在院落库量、关键字段空值率及静态检测结果，异常项闭环处理。

二、医嘱执行主题 HID0123 院区拆分需求
1、按需求推进医嘱执行主题省公卫/峨眉同库拆 HID0123、HID0124；
2、方案对齐已落地的出院/入院/在院物化视图及在院主题拆分口径，避免多主题院区编码不一致；
3、完成需求沟通与脚本调整跟进，持续验证拆分后执行主题数据完整性。

三、病理运管 6 月无数据异常排查
1、现象：病理运管侧 6 月数据为空；
2、根因：月初调度任务下线，导致下游无增量产出；
3、处置：已恢复调度并重新触发补数，数据恢复；后续关注调度启停与运管取数窗口对齐。

四、Kylin 运维与告警治理
1、配合 Kylin 网络漏洞扫描，核对异常告警逻辑，给出处理方案并指导落地；
2、完成告警集群扩展调整，同步调整告警项目，并开展日常告警运维。

五、云原生平台相关工作
1、参与云原生平台架构问题讨论；
2、对象存储部署方案与涛哥确认最终方式，并完成对象存储申请，持续跟进开通与接入。

六、手麻需求对接（遗留申请单问题）
1、跟进去年遗留手麻申请单数据问题，已与麻醉科对应老师沟通数据提取口径；
2、明确后续取数与核对安排，持续推进遗留问题闭环。

七、AI 内网测试
1、按计划开展 AI 内网环境测试，记录问题并反馈；
2、持续跟进测试结论与整改项。

八、专利与合同事项
1、数据底座专利文稿撰写修改；
2、合同续聘相关手续处理。

九、会议与业务学习
1、参加高质量数据集相关会议；
2、参加各类科室/部门业务学习会；
3、参加体检中心业务学习。

十、日常跟进
1、跟进本周重点任务完成情况，整理周报与周总结。
```
