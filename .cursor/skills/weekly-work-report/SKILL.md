# 工作周报 / 下周计划标准化

将零散工作要点整理为可直接粘贴的周报或下周推进文稿。**不要**改写成【项目】分类列表；统一用「一、二、三…」大项 +「1、2、3…」细则。

## 何时用哪种模板

| 用户意图 | 模板 |
|----------|------|
| 本周做了什么、周报、周总结、复盘 | → **本周工作** |
| 下周计划、下周推进、任务推进 | → **下周推进** |
| 同时要本周 + 下周 | 两段都输出，先本周后下周，中间空一行 |

## 输出硬规则

1. 大项：`一、二、三…`（中文序号），标题简短，可带主题/院区/系统名  
2. 细则：每项下必须有 `1、2、3…`（至少一个；通常 2～4 条）  
3. 细节程度：有数写数，有根因写根因，有处置写处置，有待办写待办；禁止空话套话  
4. 中文输出；条目末尾用中文分号 `；`（最后一条可同样用分号）  
5. 不编造数据：用户未给数量/日期则不写假数；可写「持续跟进」类定性进度  
6. 直接给出正文，默认不加前言后语；用户只要某一种时不要两种都出  
7. **换行与代码块（强制，2026-07-31 定稿）**：  
   - 最终交付**必须**包在 Markdown 围栏里：开头 ` ```text `、结尾 ` ``` `，便于复制且换行不丢；  
   - **禁止**把大项标题与 `1、2、3…` 挤在同一行（聊天/邮件会拼成一段）；  
   - 每一行只写一条：`一、…` 独占一行，其下每个 `1、` / `2、` / `3、` 各独占一行；  
   - 大项与大项之间空一行；子点 `(1)(2)…` 也各占一行；  
   - 围栏外最多一句提示（如「复制下方代码块」），正文只在围栏内。

### 正确示例（可复制形态）

````markdown
```text
一、DWD 新模型审核（护理 → 检验 → 检查 → 人员/医嘱）
1、依据前期对比收集的问题，与新主题设计方讨论分析；
2、完成护理、检验、检查、人员/医嘱 DWD 层主题表审核；
3、综合评估后确认无问题，审核结论闭环。

二、手麻从库中断导致数据集成异常
1、现象：手麻从库中断，数据集成异常；
2、处置：跟进处理，从库及集成链路已恢复；
3、后续持续关注从库连通与集成稳定性。
```
````

### 错误示例（禁止）

```text
一、DWD 新模型审核… 1、依据前期…； 2、完成…； 3、综合评估…。
```

## 本周工作模板（复盘型）

归类合并同类项后按工作包输出；**回答用户时整段仍须包在 ` ```text ` 围栏内**：

```text
一、{主题/系统/院区一句话标题}
1、{做了什么 / 核查口径 / 范围}；
2、{关键规则或方案要点，必要时写清影响边界}；
3、{已落地改动：脚本/任务/表名}；
4、{结果或下一步跟进}；

二、{下一主题}
1、{现象}；
2、{根因}；
3、{处置与后续关注}；
```

细则优先顺序（有则写，无则跳过）：

- 现象 / 需求  
- 口径或规则（院区、过滤、关联键）  
- 根因  
- 处置 / 已改文件或任务  
- 结果（条数、空置率、区间等，仅用户提供时）  
- 阻塞项与下一步  

## 下周推进模板（计划型）

标题可与本周对应，细则写**待做动作**，少写已完成复述；**同样必须用 ` ```text ` 围栏输出**：

```text
一、{推进主题}
1、{具体跟进动作}；
2、{验证/核对/闭环标准}；

二、{下一主题}
1、…；
2、…；
```

常见大项可参考（按实际素材取舍，勿硬凑）：

- 主题数据核查 / 院区拆分 / ETL  
- 平台运维与告警  
- 云原生 / 资源申请  
- 业务需求对接（手麻等）  
- 模型审核 / 问题反馈  
- 临时交付与日常跟进  

## 归类与扩写

1. 先把用户条目归并到 5～10 个大项（同类合并，勿一条一大项堆砌）  
2. 每条扩写成可验收的细则：动词开头（跟进/核查/核对/推进/配合…）  
3. 涉及 HID0123/HID0124 时写明：同库拆分、`ctloc_hospital_dr` 2→0123 / 12→0124、仅改写 HID0123、不影响其他院区（用户原文有则保留）  
4. 会议/学习可单独「九、会议与业务学习」下列 1、2、3  
5. 专利、合同、续聘等事务性工作可单独大项，细则仍用序号  

## 质量自检

- [ ] 全部是「一、」+「1、」结构，无【xxx项目】块  
- [ ] 细则有实质内容，非「完成相关工作」  
- [ ] 未虚构指标数字  
- [ ] 本周用完成态/核查态；下周用跟进/推进态  
- [ ] 正文包在 ` ```text ` 围栏内  
- [ ] 大项与每条 `1、2、3…` 均换行，无「标题+细则」同行堆叠  
- [ ] 大项之间有空行
